06 Layout

CSS Grid

Create rows, columns, and unequal layouts for visually interesting pages.

Practice: build an asymmetrical course gallery.

View example 
.layout {
  display: grid;
  grid-template-columns:
    minmax(0, 2fr)
    minmax(0, 1fr);
  gap: 1.5rem;
}
07 Responsive

Responsive Design

Start with a small-screen layout and enhance it when more space is available.

Practice: turn one column into two.

View example 
.layout {
  display: grid;
  gap: 1rem;
}

@media (min-width: 40rem) {
  .layout {
    grid-template-columns:
      repeat(2, minmax(0, 1fr));
  }
}

CSS Animations

Use keyframes to define how a component changes over time.

Practice: animate a small card without JavaScript.

View example 
@keyframes slide {
  from { transform: translateX(0); }
  to { transform: translateX(2rem); }
}

.demo {
  animation: slide 2s ease-in-out
    infinite alternate;
}
